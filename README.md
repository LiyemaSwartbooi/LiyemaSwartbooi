### What I'm working on

**[Zelpano](https://zelpano.com)** is live. It's a workflow operating system for organisations: one spine handling accounts, identity, membership, billing, audit and notifications, hosting self-contained workflows that an organisation installs from a marketplace and then runs. Claims, recruitment, onboarding, rosters, inspections, registers, approvals, or a way of working only that organisation has. The point isn't a nicer PDF of a paper form. It's removing the coordination step between two people.

Counted from the codebase rather than estimated: 241 pages across 7 route groups, 145 backend modules, 155 tables, 30 built-in workflows, 1,584 tests. Multi-tenant, self-serve, free through to enterprise pricing.

Four of those thirty workflows are installed by a real organisation today. The rest are built, deployed and installed by nobody, which is a distribution problem and not a code one. I'd rather write that down than count shipped code as customers.

It was called Depaper until August 2026. Same product, new name, and the old domain no longer resolves.

Right now I'm also learning the security side of AI-generated and agentic software. Roughly half of AI-generated code ships with a serious flaw, and most people shipping it can't tell. I'm working toward being someone who can. That's a direction, not a title, and I'll keep saying so until there's public work behind it.
